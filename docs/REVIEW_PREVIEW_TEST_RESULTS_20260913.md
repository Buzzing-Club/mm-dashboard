本轮测试计划及市场 ID 见 [测试计划](./REVIEW_PREVIEW_TEST_PLAN.md)。以下区分“接口已接”“有真实样本”和“场景验收通过”，不把接口成功等同于全部指标完成。

## 本轮发现的问题

### 策略观测计数漏记

三个市场实际有 MM_QUOTE 挂单和 maker 成交，但 `planned_orders=0`，供给有效性为 null，报价更新/盘口跟随延迟没有确认样本。

代码证据：`buzzing-mm-system/src/buzzing_mm/strategy/passive.py` 的 `_remember_planned` 仅在 dry_run 分支调用，真实路径调用 `ctx.place_batch` 未保存对应计划；Review 读取 `last_planned_orders` 因而为空。延迟观测还需要跨 tick 保留目标直至回执确认，不能简单拿某个瞬时 active order 当成计划。

建议修复并另跑一批验证：记录真实 MM 计划增量、保留有界确认目标、区分 Flash/TV，验证成交到改价确认以及公允价变化到确认两个样本。当前未改策略部署，避免测试途中重启共享 worker 干扰证据。

### 回摆观察窗无有效分母

三市场都出现 `incomplete_recross_windows`；允许的最大观察间隔为 5 秒，但实际 actor 观察存在更长间隔，且暂停/等待时 `last_fair_value` 被清空。因此 60 秒回摆窗口被判为不完整。不能用 0% 冒充有效结果，也不能仅增加成交量解决。

建议从已存在的公允价更新/成交事件接入有界观测，不为看板增加高频 DB 读取，不放宽缺失数据为连续真实值。

### 到期后持久化指标未接回 Review

到期后直接读策略 `/api/dashboard/review-observations` 仍返回 `availability=observed`、`saved_capture_count=1`、有效阶段边界，以及盘中 50% 毒性等历史计数，说明记录仍在。但 Dashboard `/api/dashboard/review-facts` 返回空的 `section_seven.metrics`，coverage 提示“缺少有效市场起止时间”。

代码位置：`app/api/dashboard/review-facts/route.ts` 仅在全局最近 catalog 中同时找到 market 与 job 时，才合并持久化 observations。到期市场退出目录后此分支失效，且 buildReviewFacts 缺少生命周期边界。需要按 condition 读取历史目录/归档身份，或从持久化边界恢复，不能依赖当前市场目录。后端成交账本和 PnL 读取仍正常，因此这不是后端缺少成交数据。

### 其他口径和体验待修

- 后台创建概率 0.50，但自动套用的策略模板 manual_f 为 0.35；应明确模板是否覆盖创建价格。本轮按实际策略输入核对。
- 策略事实 BFF 先取全局最近 1000 条再按市场过滤，市场多时历史会被挤出；需要按 condition 的有界历史查询/分页，不扩大无界内存快照。
- 部分已接指标没有触发时仍显示“待接入”，应区分未触发/阶段未开始/数据缺失。
- 尾盘尚未开始时反转次数显示 0，应该明确“阶段未开始”，不作为完成验收的负样本。
- PnL 汇总及市场搜索结果主标题都用同一个 Event 标题，三个子市场容易混淆；应显示子市场标题。
- 订单流 Score 悬停仍写“下一笔成交”，实际历史聚合使用成交后 60–90 秒公允价采样，文字需与实际近似口径一致。

### 结束快照不等于最后交易状态

三个市场在 00:45 到期，历史页随后显示 3/3，快照时间为约 00:45:12。实际冻结的是到期暂停后的策略状态，不是严格的结束前最后有效盘口。部分盘口已空，生命周期仍沿用目录中的“交易中”，需要区分计划到期与链上结算。

历史快照中的后端业务字段未合并，历史页 Gross/Net Volume、PnL 显示 unknown / 待接入；Review 可以另外读取成交和账本，但不能据此宣称实时面板中的历史快照已完整。应在有界的结束归档流程补齐截止时间明确的业务数据，并冻结最后有效策略状态，避免重新引入全量高频快照。

到期归档间隔内页面曾短暂显示“暂无市场数据”；全部当前市场结束后，必须先选择实时页“历史市场”，Review 的选择器才得到三个历史市场。当前市场为空时详情又会回退显示一个历史市场，范围和详情不一致。这些也是本轮确认的导航体验问题。

## 不在本轮伪造的样本

- 前端访问、试价和提交漏斗尚无埋点，不造用户访问数据。
- 内部测试成交不冒充自然用户；net volume/真实用户吃单档位的正样本未验收。
- 开盘 20% 内未发生 MM maker 成交，开盘毒性和开盘成交延迟没有正样本。
- 手工公平价固定为 0.35，未绕过管理鉴权或改价门禁强制造出 0.5 穿越；反转与反转后 30/120 秒敞口需另用可控合法价格输入覆盖。
- 未触发链上上报/争议/领取，不把到期归档写成完成链上结算。

## 本轮结论与收尾

- 本轮操作与采样已完成，不代表所有指标验收通过；主动脚本九笔订单均已全成，无脚本残留订单。未取消其他任务订单，也未手动结算市场。
- 00:46:30 与 00:48:00 开始的两轮读取中，三个 history item 的全部字段逐项完全相同；统一 captured_at 为 `2026-09-12T16:45:12.574748Z`，冻结稳定性通过。
- 结束后 DB checkpoint sequence 为 10，仍是三个原 capture；盘中/尾盘毒性与观察时长可直接从策略持久化 API 读取。未做共享 MM 重启验证。
- Review 后端数据到期后仍可读：市场撮合为 8/8/18 条，账户账本为 3/3/12 条，最终三个已结束交易阶段累计 PnL 为 0.51/0.51/3.491 USDB；盘后尚未结算，不能把近似估值当作最终结算收益。
- 首要修复项：历史 Review 生命周期来源及持久化合并；真实挂单计划计数与延迟确认；回摆观察窗口；历史快照业务字段和结束前状态语义。前端行为埋点和自然用户正样本另外覆盖。
- Preview 暂时仍只显示这三个测试市场；现在请在实时页选择“历史市场”，再切换 Review。其他市场、数据和任务未删除；Vercel Mock 未修改。
