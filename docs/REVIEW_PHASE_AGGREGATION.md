# 阶段聚合与策略观测

## 产品范围确认（2026-09-12）

- 做市 Review 是非实时复盘。优先读取已有成交、账本、决策、订单与观测历史，或读取已累计的统计结果，再按市场和阶段离线聚合；不要求后端提供实时计算好的指标接口。
- 已有原始事实但尚未组合展示，属于 Dashboard/策略侧聚合与接入工作，不能列成后端缺指标 API。只有必要原始事实从未记录、现有来源无法推导时，才单独列为采集缺口；例如仅凭成交无法反推未成交用户的访问或试价行为。
- 首版接受有来源说明的 pre_batch 盘口、近似估值与采样统计，不为提高精度扩大接口或实时服务范围。数据缺失与真实零值仍须区分。
- 历史市场快照属于实时看板的“历史市场”子功能，与做市 Review 独立。市场结束时持久保留结束时的最后有效展示状态，之后从快照读取；不要求逐时点回放，也不为此新增每30秒保存全市场状态的周期任务。
- 结束快照不是全过程历史，不能据此还原中途的成交、反转或延迟。Review 需要的过程统计走已有历史记录或必要的有界累计，不把实时看板的结束快照扩展成完整历史采集系统。

## 策略观测接入

Dashboard `/api/dashboard/review-facts` 在原有历史采样之后，只查询选中账户和市场的 `/api/dashboard/review-observations`。要求 contract v1、condition/account 一致、唯一实际运行 revision、捕获未失败，且开始/结束时间与目录一致；有歧义不跨账户相加。配置期望 revision 与运行版本不同时，明确标注而不把两版相加；读取失败仍保留原有历史采样并注明原因。

新增映射：开盘毒性率、盘中回摆率、NORMAL 双边健全率、供给转化、开盘报价更新 P50/P95、盘口跟随 P50/P95。加上原有六项历史采样及后端用户吃单档位，十三项均已有消费路径；没有成熟样本仍为空，不表示接口尚未开发。

- 持久累计毒性按已完成30秒分类的成交计算，分类覆盖率另列；未分类窗口不算零。旧内存接口仍保留其原始全分类口径。
- 回摆使用完成 60 秒观察窗的数据，超过 5 秒空档不猜测；买入/卖出方向计数已映射。
- 健全率分母为已观察秒数，不冒充完整生命周期时长。
- 延迟为 actor 观察触发到变化报价确认的采样上界；持久模式合并固定累计直方图后计算P50/P95（桶上界），不是平均分位数或分层网络端到端延迟。
- 供给为捕获区间 MM_QUOTE maker 成交 / 语义变化时计划行，不声称是任务启动以来全量。
- 策略新增独立Review累计持久化：每运行段幂等覆盖检查点，重启开启新段，接口按账户/任务/相同市场边界合并并报告空档。历史与当前同一capture只计算一次。过去已丢失的内存统计不能恢复；未部署新生产者时仍显示“当前内存观测，未确认持久化”。该功能不改变实时看板的结束快照。

## 阶段估值

在已有后端有界读取结果上，将成功账本按纳秒排序、entry_id 去重，按 position、ownership、funding account 隔离库存。阶段使用各市场起止时间 20/60/20，盘后另列。

1. buy/split 增加库存和成本，扣现金；sell/merge 减少库存，计收入；成交手续费扣一次。
2. win/lose 减库存并确认结算应收；claim 仅兑现已经确认的应收，不重复加利润。
3. 阶段末持仓估值使用截止点之前最近可用市场成交价、pre_batch mid 或账户成交价，YES/NO 互补，明确标注来源与时间。绝不使用截止点之后的价格倒填。
4. 无剩余库存不用价格；YES/NO 数量相等时用一套配对兑付 1 USDB 的恒等式。方向性库存没有历史参考价格时留空。
5. 累计近似 PnL = 累计净现金流（含结算应收）+ 剩余持仓估值。阶段 PnL = 阶段末累计值 - 阶段初累计值。不能相加三个阶段的累计值。
6. 未实现 PnL = 剩余持仓估值 - 按含费加权成本重建的剩余成本。它与后台权威值可能因转换成本口径、历史覆盖和估值时点不同而有差异，所以标近似，不覆盖后台权威当前 PnL。
7. 缺账本、来源库存不足、资金归属不明或截断时不输出伪完整值。未来阶段留空。单市场 FIFO 已处置敞口归因独立保留，不能与点差及阶段总 PnL 相加。

例：开盘买 10 shares @0.4、费 0.1，阶段末仍按0.4估值，开盘 PnL=-0.1。盘中卖5@0.6、费0.1，余5按0.6估值，累计1.8、盘中1.9。尾盘价格0.8，累计2.8、尾盘1.0。盘后剩余5以1结算，累计3.8、盘后1.0；随后claim不再增加收益。

## 组合计算与资源

PnL 分区新增阶段汇总按钮，按已加载的当前及历史市场去重，逐个顺序请求，单市场间隔300ms。每轮固定市场列表及同一个 `as_of` 截止秒数，分阶段汇总 PnL、已覆盖点差与已处置敞口，并显示各自可计算市场数及逐市场缺口。可停止/继续；期间历史市场列表迟到或实时刷新不会清空结果或中止本轮。重新计算会清空旧轮次，并使用最新列表及新截止时间。

默认不在打开页面时触发全量复盘；浏览器只保留小型阶段结果，不保留原始成交/账本/批次。离开页面停止调度。服务端仍保留每来源8页、500条/页、2MB/页、45秒总时限、最多两个并发、60秒缓存最多24市场的限制。大市场未完全覆盖会显示部分结果，不把缺失当0。

`summary=1` 不返回 FIFO 明细；`as_of` 必须是非未来的正整数 Unix 秒。历史范围是看板已加载的市场，不冒充平台未知市场的全量收益。

## 验证

Dashboard 43 项测试包括费用、部分平仓、历史价的禁止未来引用、配对库存、盘后结算、claim不重复、组合非累计叠加，以及六项观测的账户/版本/时间边界校验。类型检查及 app/tests lint 通过。MM 本地全量1413项通过，Preview CI 再次执行全量测试。真实部署结果追加到相关 PR。

2026-09-11 Preview 候选验证：浏览器固定首批53个市场，53/53请求成功；暂停于16个后可继续完成。开盘可计算52/53、阶段PnL约0.85 USDB，盘中45/53、约3.27 USDB，数值仅为当轮截止快照，不是全平台统计。迟到的历史市场列表扩为551个，不影响固定轮次，可重算纳入。1440和390像素宽度均无页面横向溢出，明细在容器内滚动。

MM #459 部署后，旧任务返回 `start_time_source=catalog_start_or_create_time`、`phase_bounds_valid=true`，真实双边健全秒数增长，Dashboard 已收到健全率正样本。无成交或无确认报价变化的指标保持空样本，并保留捕获时间和覆盖率，不伪造毒性、回摆和延迟数据。
